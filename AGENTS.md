# AGENTS.md — Ozon SKU Shop Best Offers

## Назначение

Веб-расширение Manifest V3 для Яндекс Браузера и Google Chrome, добавляющее колонку «Цена за отзыв» в таблицу «Магазин карточек» Ozon Seller. Основной URL: `https://seller.ozon.ru/app/items/store?activeTab=allListings`.

## Архитектура

- `manifest.json` — минимальные разрешения: `content_scripts` на `https://seller.ozon.ru/*`, без `permissions`, `host_permissions`, фонового service worker или внешних библиотек. Широкий матч нужен для переходов Ozon SPA; скрипт проверяет конкретный `location.pathname`.
- `content.js` — самодостаточный IIFE. Читает видимые DOM-значения, добавляет `th[data-ozrp-header]` и `td[data-ozrp-cell]`, слушает MutationObserver, пересчитывает с debounce 70 мс.
- `style.css` — стили только для размеченных расширением ячеек.
- `icons/` — PNG-иконки для расширения.
- `tests/test_extension.py` — Playwright DOM-регрессионные тесты на синтетических данных, которые можно коммитить.

## Инварианты

1. Новый столбец **сразу после** нативного `Контент-рейтинг` / `Контент рейтинг`.
2. Цена = отображаемая цена карточки / количество отзывов. Деление на ноль запрещено. Отображать с двумя знаками после запятой, сравнивать исходные неокруглённые значения.
3. Подсветка только для цены строго ниже 100 ₽.
4. В один момент времени максимум один «Лучший оффер» в таблице; при равенстве — первая строка в DOM.
5. Карточка с текстом `Убрать из корзины`, `Удалить из корзины` или `В корзине` не участвует в выборе лучшего оффера. Возврат в корзину/из корзины должен приводить к повторному поиску.
6. Пустые строки загрузки не должны получать добавленных ячеек.
7. Фильтры, изменение цен, сортировка, страницы и Vue-перерисовки не должны ломать расширение или приводить к дублированию колонок.
8. Не обращаться к API Ozon, не вмешиваться в штатные клики, не хранить токены, не отправлять данные наружу.

## Разработка и проверка

```bash
node --check content.js
pip install playwright
python -m playwright install chromium
python -m unittest discover -s tests -p 'test_extension.py' -v
```

При изменении парсинга, логики корзины или работы MutationObserver обязательно запускать тесты. Проверить вручную переключение `Добавить в корзину → Убрать из корзины → Добавить в корзину` на авторизованной странице Ozon. Тесты на синтетическом DOM не гарантируют совместимость со всеми будущими изменениями сайта.

## Стиль коммитов

Изменять только необходимые файлы. Не коммитить токены, cookies, приватные сохраненные HTML-страницы, дампы seller-данных и `__pycache__`. Держать README на русском. Сохранять совместимость Chromium Manifest V3 и установку через `browser://extensions` / `chrome://extensions`.
